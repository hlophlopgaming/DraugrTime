# Draugr Time 1.1.1

Fixes "start at login" for the Linux AppImage.

## Fixed

- **Linux AppImage start-at-login.** Enabling *Start Draugr Time when I log in*
  recorded the executable path inside the AppImage's temporary squashfs mount
  (`/tmp/.mount_…/usr/bin/draugr-time`), which disappears when the app exits, so
  nothing launched at login. The autostart entry now points at the persistent
  `.AppImage` file via `$APPIMAGE` and falls back to the executable path when not
  running from an AppImage.

  If you enabled startup in 1.1.0, toggle the setting off and on again once so
  the corrected path is registered.

## Install

Same artifacts as 1.1.0: Windows installer + portable zip, macOS DMG, Linux
AppImage + portable archive. History remains local; no telemetry or network
updater.
