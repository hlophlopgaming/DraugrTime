# Draugr Time 1.3.0

Backups, timed pauses that survive restarts, faster quick tagging and keyboard shortcuts.
**Draugr Time is in active development:** the interface and features are still evolving.

## What's new

- **Backups:** Settings → Data & import → Backups. **Back up now** copies your
  history while recording continues. Automatic backups run daily or weekly and keep
  the newest 3, 7, 14 or 30 copies; manual backups are never deleted. Backups are
  stored in the `backups` folder inside your data folder.
- **Restore:** pick a backup and Draugr Time replaces your history with it on the
  next launch. Your current history is kept as a "Before restore" backup, and a
  waiting restore can be cancelled until then. Damaged files are never applied.
- **Timed pauses after a restart:** if Draugr Time restarts during a "Don't track
  for…" pause (crash, update, reboot), the pause continues until its original end
  instead of recording right away. An expired pause is dropped.
- **Tag the last N minutes:** the tray has **Tag last N minutes…**, and the tag
  editor for a new range has 5/15/30/60 minute buttons and a minutes field
  (up to 24 hours).
- **Keyboard shortcuts:** **Ctrl/⌘+1…5** switch between Day, Week, Tags, Rules and
  Settings; **P** pauses for your last chosen time or resumes; **N** tags the last
  N minutes; **F1** or **?** lists every shortcut. Shortcuts work inside the window
  when no text field is focused.

## Install

- **Windows:** use the per-user Setup executable or extract the portable ZIP. Both
  include `draugr-time-cli.exe`.
- **macOS:** open the DMG and drag Draugr Time to Applications, or use the portable
  archive. The bundle is ad-hoc signed, not Developer ID signed/notarized; macOS may
  require Privacy & Security → Open Anyway.
- **Linux:** make the AppImage executable and run it, or extract the portable archive.
  Quit an older running instance through its tray before starting the new version.

Your history stays in its existing local data folder. No account, telemetry, cloud
uploads or network updater is added. Uninstalling does not delete stored history or
backups. The database format is unchanged, so 1.2.x can still open it.

## Known limitations

- Automatic backups are on by default (daily, 7 copies). Each copy is a full copy
  of the history; turn them off or keep fewer in Settings if disk space is tight.
- Backups go to a fixed folder inside the data folder; a separate backup location
  is not available yet.
- Shortcuts are not system-wide: Wayland has no portable way to register them.
- Pausing, quick tagging, shortcuts and backup/restore were tested automatically;
  checks on real Windows, macOS and Wayland desktops are still pending.
- Windows installers are not publisher-signed; macOS bundles are not notarized.
