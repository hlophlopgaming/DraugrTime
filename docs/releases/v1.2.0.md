# Draugr Time 1.2.0

A redesigned desktop interface, title masking and more responsive local tracking.
**Draugr Time is in active development:** the interface and features are still evolving.

## What's new

- **New dark and light interface:** bundled Inter Tight and JetBrains Mono fonts,
  refreshed branding, compact navigation and layouts that adapt to narrow windows.
- **Day timeline:** active-hours/full-day/selection ranges, clearer track spacing,
  expandable application/document lanes, selection actions, an hourly activity chart
  and a filterable Apps/Documents/Tags panel.
- **Week, Tags and Rules:** weekly timelines and timesheets, a hierarchical tag table
  with an editor, and ordered rules with live previews and undoable history tagging.
- **Settings and tray:** six settings sections, removable privacy-list entries, timed
  pauses of 5/10/15/30/60 minutes, Resume and +5/+15 extensions. New installations
  get a one-time startup-at-login question; existing installations are not asked again.
- **Motion and accessibility:** short, interruptible transitions, keyboard controls,
  visible focus and reduced-motion support. Animation frame timers stop when complete
  or when the window loses focus or closes.
- **Title masking:** selected applications keep their recorded time while new window
  titles are replaced with `[masked]`. Exclusions take precedence; existing history
  is not rewritten.
- **Resource use:** fewer background UI wakeups, release-time optimization, indexed
  tag lookups and improved memory reclamation. No new idle CPU/PSS claim is made for
  the redesign without native measurements.

## Fixes

- The first-launch CI diagnostic now answers the new startup question before checking
  that Day view is recording, preventing its onboarding timeout.
- The Windows installer reports the same version as the application; a regression
  check keeps the two versions aligned.

## Install

- **Windows:** use the per-user Setup executable or extract the portable ZIP. Both
  include `draugr-time-cli.exe`.
- **macOS:** open the DMG and drag Draugr Time to Applications, or use the portable
  archive. The bundle is ad-hoc signed, not Developer ID signed/notarized; macOS may
  require Privacy & Security → Open Anyway.
- **Linux:** make the AppImage executable and run it, or extract the portable archive.
  Quit an older running instance through its tray before starting the new version.

Your history stays in its existing local data folder. No account, telemetry, cloud
uploads or network updater is added. Uninstalling does not delete stored history.

## Known limitations

- Timed pauses are not restored after restarting the process. Backups and ActivityWatch
  category interchange remain planned work; existing history import/export remains.
- Date changes that load history settle immediately; an old/new day cross-fade is not
  implemented. Unknown reduced-motion preferences conservatively skip animation.
  Windows/macOS preferences refresh when the app regains focus.
- GNOME/KDE Wayland tracking still needs its local bridge. Real-desktop permission,
  input and idle-memory checks remain platform-dependent; CI does not replace these.
- Windows installers are not publisher-signed; macOS bundles are not notarized.
