# Draugr Time 1.2.1

Layout fixes and fewer background history updates.
**Draugr Time is in active development:** the interface and features are still evolving.

## Changes

- Expanded timeline lane labels stay on one line instead of overlapping adjacent rows.
- The Day summary scrollbar has its own space and no longer covers highlight buttons.
- The Week panel shows up to 10 most-used applications instead of 5.
- Live history loading stops when the window loses focus, including when minimized.
  Background recording continues, and history refresh resumes on focus. Visible
  unfocused windows also pause history refresh because Wayland does not provide a
  portable minimized-state query through the current UI framework.

## Verification and limitations

- A regression test covers 7,200 queued ticks without hidden history loads and
  confirms that loading resumes on focus. This is not a two-hour memory measurement;
  the reported growth to 300 MiB still needs verification in a real desktop session.
- Windows installers are not publisher-signed; macOS bundles are not notarized.
- Quit the previous instance through its tray before starting the new version.
  Your local history remains in its existing data folder.
