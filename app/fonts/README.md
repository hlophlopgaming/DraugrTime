# Bundled fonts

- `InterTight.ttf`: Inter Tight variable upright, from
  https://github.com/google/fonts/tree/main/ofl/intertight
- `JetBrainsMono-Regular.ttf`: JetBrains Mono Regular, from
  https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/ttf

Downloaded on 2026-10-22. The adjacent `*-OFL.txt` files contain the respective
SIL Open Font License notices. Both fonts are embedded into the executable;
the application never downloads fonts. System fallback supplies glyphs outside
these fonts' coverage (including Chinese and Japanese).
